## 2. 背景與問題陳述

本系統透過 RTSP 或 Webcam 擷取畫面，使用 YOLOv8 偵測人體，配合「ROI + 人體框高度門檻 + 去抖動」判定是否在座，內建工作 / 短暫離開 / 提醒中的計時狀態機，並提供彈出視窗、系統通知、置頂懸浮倒數三種提醒；工作 / 休息紀錄寫入 SQLite。

目前在「設定可用性」與「UI/UX 完整度」上有以下痛點：

1. **設定介面不完整且無引導**：已有 `src/ui/settings.py`（`QDialog` + `QFormLayout`），但
   - 沒有任何提示說明，使用者不知道每個參數的意義。
   - 只開放部分參數，缺少偵測間隔、運算裝置、重連間隔、重複提醒間隔、貪睡時間、紀錄、開機最小化等。
   - 沒有「重新啟動後生效」的提示。
   - `SettingsDialog.config_changed` 訊號在 `src/main.py` **未接線**，導致改設定只寫入 `config.yaml`、對執行中的程式毫無作用（實際上已需手動重啟，卻沒有告知使用者）。
2. **分鐘欄位無法精細設定**：計時門檻使用 `QDoubleSpinBox` 但未設定範圍與步進，受預設上限（99.99）與整數步進限制，無法輸入 0.1 分等細值，不利測試與長工時情境。
3. **主視窗過於陽春**：僅「影像預覽 + 三行純文字標籤」垂直堆疊，無視覺層級，亦無載入中 / 連線 / 重連 / 無訊號 / 錯誤等狀態呈現。
4. **缺少系統匣圖示**：執行時出現 `QSystemTrayIcon: No Icon set`。
5. **提醒媒體毀損無降級**：執行時出現 `libpng IDAT CRC error`，預設提醒圖片可能毀損，且載入失敗時無預設替代。
6. **終端被解碼噪音洗版**：大量 `co located POCs unavailable`、`bad cseq`、`error while decoding…` 等 RTSP/H264 訊息掩蓋了真正有意義的事件記錄。
7. **缺乏基本品質**：未支援深色模式、無障礙考量不足。

## 3. 目標與非目標

### 3.1 目標（Goals）

- G1：提供易用、可發現、**每個欄位都有提示**的設定頁面；儲存後明確提示「重新啟動後生效」。
- G2：所有以分鐘為單位的欄位支援 **0.1 ~ 9999 分、精度 0.1**。
- G3：依 Apple HIG 原則（轉譯到 Qt）重整主視窗、系統匣與提醒，建立清楚層級與一致文案。
- G4：補齊執行品質：壓制解碼 log 噪音、補應用程式 log 檔、系統匣圖示、媒體降級、完整 UI 狀態。
- G5：深 / 淺色跟隨 Windows 系統主題；達成務實的無障礙子集。

### 3.2 非目標（Non-Goals）

- 不改寫技術棧：維持 PySide6 / Qt，不轉 SwiftUI / Web。
- 不更動人體偵測演算法、在場判定邏輯、計時狀態機的核心行為。
- 不新增雲端、帳號、多攝影機、多語系（本次僅繁體中文）。
- 不做完整歷史 / 統計頁，本次只做**今日簡單彙總**。
- 不處理自動更新、安裝包等發佈議題。

## 4. 設計原則（Apple HIG → Qt 轉譯）

| Apple HIG 原則 | 在本專案（Qt）的落地方式 |
|---|---|
| 內容優先 | 主視窗以攝影機預覽為主角，狀態與控制項服務內容、不喧賓奪主。 |
| 系統原生優先 | 優先使用 `QFormLayout`、`QListWidget`（側邊欄）、`QStackedWidget`、`QMessageBox` 等原生控制項，避免自刻基礎元件。 |
| 克制而明確 | 以留白、字級、語意色彩、內容分組建立層級，而非堆疊陰影 / 外框 / 漸層。 |
| 語意字級與色彩 | 以 QSS 定義 typography 與 color token，不硬編 px 與顏色；深 / 淺色各一套。 |
| 可行動文案 | 按鈕使用動詞（開始休息、再 5 分鐘、儲存變更）；錯誤訊息說明「發生什麼 + 為什麼 + 怎麼辦」。 |
| 無障礙是基本規格 | 鍵盤可達、控制項具可讀標籤、對比足夠、狀態不只靠顏色。 |
| 狀態驅動 UI | 每個畫面都定義 正常 / 載入 / 空 / 錯誤 / 深色 狀態。 |

## 6. 功能需求

### FR-1 設定頁面

- **FR-1.1**　形式為獨立設定視窗：左側分類清單（基本 / 偵測 / 提醒 / 紀錄 / 進階），右側對應表單（以 `QStackedWidget` + `QFormLayout` 實作）。
- **FR-1.2**　開放全部 `config.yaml` 參數（詳見 §9 對照表），依分類擺放。
- **FR-1.3**　每個欄位下方常駐一行輔助說明文字（次要文字色），不需滑鼠停留或點擊即可看到。
- **FR-1.4**　所有分鐘欄位（`work_threshold_min`、`reset_threshold_min`、`required_rest_min`、`repeat_interval_min`、`snooze_min`）：範圍 **0.1 ~ 9999**、`singleStep = 0.1`、顯示 1 位小數。
- **FR-1.5**　輸入驗證就近顯示：RTSP 模式 URL 不可為空、信心門檻 `0 < x ≤ 1`、在場大小門檻 `0 < x ≤ 1`、去抖動次數為 `≥ 1` 的整數、分鐘欄位需落在 0.1~9999；無效時阻擋儲存並於欄位附近提示。
- **FR-1.6**　操作為「儲存 / 取消」；**儲存成功後跳提示**「設定已儲存。部分變更需要重新啟動程式後才會生效。」（僅手動重啟，不提供自動重啟按鈕）。
- **FR-1.7**　來源類型（rtsp / webcam）切換時，動態顯示 / 淡化相關欄位（RTSP URL 對 Webcam Index）。
- **FR-1.8**　設定頁**不含 ROI**；ROI 改於主視窗以直接操作編輯（見 FR-2.5），以避免「設定頁需重啟、主視窗卻即時」的不一致。
- **FR-1.9**　鍵盤可達：`Tab` 巡覽、`Enter` 儲存、`Esc` 取消，焦點順序合理。

### FR-2 主視窗

- **FR-2.1**　內容優先版面：大型攝影機即時預覽（含 ROI 疊加框）為畫面主角。
- **FR-2.2**　狀態列：呈現狀態（待機 / 工作中 / 短暫離開 / 提醒中）· 計時 · 接近工作門檻的進度條。
- **FR-2.3**　今日簡單彙總：今日工作時長、休息次數（資料來源：SQLite）；無資料時顯示空狀態文案。
- **FR-2.4**　動作列：編輯 ROI（切換編輯模式）、暫停 / 繼續偵測、開啟設定。
- **FR-2.5**　ROI 編輯：於預覽上直接框選，**即時套用**到偵測，放開滑鼠時寫回 `config.yaml`。
- **FR-2.6**　連線 / 執行狀態完整呈現：待機、連線中、已連線、重連中、無訊號、錯誤；各有對應文案與語意色彩，並**搭配文字 / 圖示**（不只靠顏色）。
- **FR-2.7**　關閉視窗 = 隱藏到系統匣（維持現行行為），而非結束程式。

### FR-3 系統匣與提醒

- **FR-3.1**　提供 app / 系統匣圖示（取代 `No Icon set`）；tooltip 隨狀態更新。
- **FR-3.2**　系統匣選單：開啟主視窗、暫停 / 繼續偵測、設定、結束（維持並校正文案）。
- **FR-3.3**　三種提醒（popup / toast / floating）統一視覺語言與文案；主要動作明確（**開始休息**），次要動作（**再 5 分鐘** / **關閉**）。
- **FR-3.4**　提醒以語意色彩搭配文字 / 圖示雙重表達，不只靠顏色。
- **FR-3.5**　媒體（圖片 / 影片 / 音效）載入失敗時優雅降級到預設替代，不報錯、不崩潰（對應 `libpng IDAT CRC error`）。

### FR-4 執行品質與穩健性

- **FR-4.1**　壓制 OpenCV / FFmpeg / libav 的解碼噪音（調整對應 log 等級 / 環境變數），終端只保留有意義輸出。
- **FR-4.2**　應用程式自有結構化 log，寫入可輪替的 log 檔（如 `data/logs/app.log`）。
- **FR-4.3**　RTSP 斷線不崩潰、能重連，並把狀態反映到 UI（見 FR-2.6）。
- **FR-4.4**　缺失 / 毀損資產（系統匣圖示、提醒圖片）皆有預設替代與防呆。

### FR-5 主題（深 / 淺色）

- **FR-5.1**　以 QSS 定義淺色與深色兩套語意 token（背景、主要文字、次要文字、強調色、危險色、分隔線等）。
- **FR-5.2**　啟動時依 Windows 系統主題自動選擇；（可選）監聽系統主題變更並即時切換。
- **FR-5.3**　兩套主題皆需通過對比與可讀性檢查。

### FR-6 無障礙（務實子集）

- **FR-6.1**　完整鍵盤操作與合理 `Tab` 焦點順序。
- **FR-6.2**　所有控制項（尤其 icon-only）設定 `accessibleName` / `accessibleDescription`。
- **FR-6.3**　文字與背景對比達可讀標準；狀態不只靠顏色。
- **FR-6.4**　避免以固定高度卡死文字；於合理範圍內尊重系統字級。

## 7. 非功能需求

- **效能**：UI 不阻塞；偵測續留 worker thread；預覽更新流暢；log 寫入不影響主迴圈。
- **相容性**：Windows 11、Python 3.11+、PySide6；沿用既有分層架構（核心純邏輯 / I/O 介面卡 / Qt 接線 / Qt UI / 組裝入口）。
- **可維護性**：主題、文案、設定 schema 集中管理；新增設定欄位採單一可擴充模式；維持既有測試綠燈並補對應測試。
- **國際化**：本次僅繁體中文，但文案集中以利日後擴充。

## 9. 設定參數分類對照表

> 套用方式：**設定頁的所有參數變更皆採「儲存後手動重啟」生效**。唯一的即時項目是主視窗的 ROI 框選（FR-2.5），不在本表內。

### 基本

| 參數鍵 | 控制項 | 範圍 / 選項 | 提示文字（草稿） |
|---|---|---|---|
| `source.type` | 下拉 | rtsp / webcam | 選擇影像來源：網路串流（RTSP）或本機 Webcam。 |
| `source.rtsp_url` | 文字 | rtsp 時不可空 | RTSP 串流位址，例 `rtsp://帳號:密碼@主機:554/stream`。 |
| `source.webcam_index` | 數字 | ≥ 0 整數 | 本機攝影機編號，通常 0 是內建鏡頭。 |
| `timer.work_threshold_min` | 小數 | 0.1 ~ 9999，step 0.1 | 連續工作達此時間就提醒休息。 |
| `timer.reset_threshold_min` | 小數 | 0.1 ~ 9999，step 0.1 | 離開超過此時間，才把工作計時歸零。 |
| `timer.required_rest_min` | 小數 | 0.1 ~ 9999，step 0.1 | 離開達此時間才算真正完成休息。 |

### 偵測

| 參數鍵 | 控制項 | 範圍 / 選項 | 提示文字（草稿） |
|---|---|---|---|
| `detection.confidence` | 小數 | 0 < x ≤ 1，step 0.05 | 人體偵測的最低把握度，越高越嚴格、誤判越少但可能漏抓。 |
| `presence.min_box_height_ratio` | 小數 | 0 < x ≤ 1，step 0.05 | 人體框需占畫面高度的最小比例，用來濾掉遠處的人。 |
| `presence.debounce_count` | 數字 | ≥ 1 整數 | 連續幾次判定一致才改變在場狀態，避免閃爍誤判。 |
| `detection.interval_sec` | 小數 | > 0 | 每隔幾秒做一次偵測，越短越即時但越耗資源。 |

### 提醒

| 參數鍵 | 控制項 | 範圍 / 選項 | 提示文字（草稿） |
|---|---|---|---|
| `reminder.method` | 下拉 | popup / toast / floating | 提醒呈現方式：彈出視窗、系統通知、置頂懸浮倒數。 |
| `reminder.reset_mode` | 下拉 | detection / dismiss / snooze | 提醒後如何重置：離開才重置 / 按掉即重置 / 先貪睡。 |
| `reminder.repeat_interval_min` | 小數 | 0.1 ~ 9999，step 0.1 | 未處理時，每隔多久再提醒一次。 |
| `reminder.snooze_min` | 小數 | 0.1 ~ 9999，step 0.1 | 按下貪睡後，延後多久再次提醒。 |
| `reminder.popup.media_path` | 文字 + 瀏覽 | 檔案路徑 | 提醒時顯示的圖片或影片檔路徑。 |
| `reminder.popup.media_type` | 下拉 | image / video | 上面媒體的類型。 |
| `reminder.popup.sound_path` | 文字 + 瀏覽 | 路徑 / 留空 | 提醒時播放的音效檔，留空則不播放。 |
| `reminder.floating.position` | 下拉 | 四角位置 | 置頂懸浮倒數視窗出現的位置。 |

### 紀錄

| 參數鍵 | 控制項 | 範圍 / 選項 | 提示文字（草稿） |
|---|---|---|---|
| `logging.enabled` | 開關 | 是 / 否 | 是否把工作 / 休息紀錄寫入資料庫。 |
| `logging.db_path` | 文字 + 瀏覽 | 檔案路徑 | 紀錄資料庫（SQLite）檔案位置。 |

### 進階

| 參數鍵 | 控制項 | 範圍 / 選項 | 提示文字（草稿） |
|---|---|---|---|
| `detection.model_path` | 文字 + 瀏覽 | 檔案路徑 | YOLOv8 模型權重檔路徑。 |
| `detection.device` | 下拉 | auto / cpu / cuda | 運算裝置：自動 / CPU / GPU（CUDA）。 |
| `source.reconnect_interval_sec` | 小數 | > 0 | 串流斷線後，每隔幾秒嘗試重新連線。 |
| `ui.start_minimized` | 開關 | 是 / 否 | 啟動時直接最小化到系統匣。 |

## 11. UX 文案準則與關鍵字串

**準則**：短、清楚、可行動；按鈕用動詞；錯誤訊息含原因與下一步；不只靠顏色傳達狀態。

| 情境 | 文字（草稿） | 動作 |
|---|---|---|
| 儲存成功 | 設定已儲存。部分變更需要重新啟動程式後才會生效。 | 知道了 |
| RTSP URL 空 | 請先填入 RTSP 串流位址。 | — |
| 無訊號 | 目前收不到影像。請確認攝影機或串流來源後再試一次。 | 重試 |
| 重連中 | 連線中斷，正在重新連線… | — |
| 提醒 | 標題「該休息一下了」／內文「你已連續工作 OO 分鐘。」 | 開始休息 / 再 5 分鐘 / 關閉 |
| 今日彙總空 | 今天還沒有紀錄，開始工作後就會出現在這裡。 | — |
| 媒體缺失 | （靜默降級為預設畫面，不打斷使用者；錯誤寫入 log 檔。） | — |
