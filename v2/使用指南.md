# 人員監測與工作時間管理系統 - 使用指南

## 🚀 系統特色

### 主要功能
- **自動計時**：只在檢測到使用者時計算工作時間
- **智能重置**：離開超過設定時間自動重置計時器  
- **工作記錄**：詳細記錄每日工作時段和休息情況
- **休息提醒**：支援計時器和圖片兩種提醒模式
- **統計分析**：提供工作時間統計和分析功能

## 📋 安裝需求

### 必需套件
```bash
pip install ultralytics opencv-python Pillow
```

### 系統需求
- Python 3.8+
- 攝像頭 (內建或外接)
- YOLO 模型檔案：`D:\Code\Models\yolov8n.pt`

## ⚙️ 配置說明

### 時間參數
- `WORK_DURATION`: 3600秒 (1小時) - 工作時長統計和長時間工作提醒
- `REST_INTERVAL`: 1800秒 (30分鐘) - 定期休息提醒的週期
- `REST_DURATION`: 300秒 (5分鐘) - 建議的休息時長
- `AWAY_THRESHOLD`: 300秒 (5分鐘) - 離開座位的判定閾值
- `DETECTION_INTERVAL`: 1秒 - 攝像頭檢測頻率

### 休息提醒模式
1. **計時器模式** (`REST_REMINDER_MODE = "TIMER"`)
   - 顯示倒數計時器視窗
   - 可提前關閉或暫停
   - 置頂顯示選項

2. **圖片模式** (`REST_REMINDER_MODE = "IMAGE"`)
   - 顯示自訂休息圖片
   - 圖片路徑：`images/image.png`
   - 支援視窗或全螢幕模式

## 🖥️ 使用方法

### 啟動程式
```bash
cd v2
python main.py
```

### 操作說明
1. 程式啟動後會自動檢測攝像頭
2. 選擇要使用的攝像頭索引
3. 系統開始監測人員狀態
4. 按 'q' 鍵或 Ctrl+C 退出

### 功能說明
- **人員檢測**：系統自動檢測攝像頭前是否有人
- **工作計時**：只在檢測到人員時計算工作時間
- **休息提醒**：每30分鐘提醒休息一次
- **智能重置**：離開超過5分鐘自動暫停計時
- **記錄保存**：工作記錄自動保存為 JSON 檔案

## 📊 輸出檔案

### 每日工作記錄
- 檔案格式：`work_log_YYYY-MM-DD.json`
- 內容：工作時段、總時間、統計資料

### 工作報告
- 檔案格式：`work_report_YYYY-MM-DD.txt`
- 內容：詳細工作統計和效率分析

### 範例配置檔案
- 檔案名：`config_sample.py`
- 內容：完整的配置參數範例

## 🔧 故障排除

### 常見問題
1. **攝像頭無法開啟**
   - 檢查攝像頭是否被其他程式占用
   - 嘗試不同的攝像頭索引

2. **模型檔案不存在**
   - 確保 YOLO 模型在指定路徑
   - 下載 yolov8n.pt 模型檔案

3. **圖片提醒無法顯示**
   - 檢查圖片檔案是否存在
   - 系統會自動切換為計時器模式

4. **GPU 無法使用**
   - 系統會自動降級使用 CPU
   - 安裝 CUDA 支援可提升效能

## 🎯 使用建議

### 最佳實踐
- 確保攝像頭角度能清楚檢測到人員
- 定期檢查工作記錄檔案
- 根據個人習慣調整時間參數
- 使用圖片模式時選擇護眼圖片

### 效率提升
- 遵循 30 分鐘工作 + 5 分鐘休息的節奏
- 關注工作效率分析建議
- 定期查看每日工作報告
