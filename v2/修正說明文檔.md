說明：

應用目的：透過攝像頭即時監控使用者是否在電腦前工作，並在適當時機提醒休息。

功能特色：

- **自動計時**: 只在檢測到使用者時計算工作時間
- **智能重置**: 離開超過設定時間自動重置計時器
- **工作記錄**: 詳細記錄每日工作時段和休息情況
- **統計分析**: 提供工作時間統計和分析功能
- **可自訂設定**: 使用者可以靈活調整工作時間和休息提醒間隔
- **自動記錄每日工作時段**
- **追蹤休息和中斷時間**

### 功能概述
當定期休息提醒的週期（`REST_INTERVAL`）到達時，系統提供兩種休息提醒模式供使用者選擇，以滿足不同使用習慣和工作環境需求。

### 提醒模式詳細說明

#### 模式 1：倒數計時器模式
**功能描述**：跳出視窗式倒數計時器
- **顯示內容**：`REST_DURATION` 時間的倒數計時（預設5分鐘）
- **視覺效果**：獨立視窗，顯示剩餘休息時間
- **互動方式**：
  - 可提前關閉計時器
  - 支援暫停/繼續功能
  - 時間到達時自動關閉
- **適用情境**：需要嚴格控制休息時間的使用者

#### 模式 2：圖片提醒模式
**功能描述**：顯示自訂休息提醒圖片
- **圖片位置**：`images/image.png`
- **顯示時長**：`REST_DURATION` 時間（預設5分鐘）
- **視覺效果**：全螢幕或視窗式顯示提醒圖片
- **互動方式**：
  - 可點擊關閉
  - 支援按鍵關閉（如ESC鍵）
  - 時間到達時自動關閉
- **適用情境**：偏好視覺提醒或需要護眼圖片的使用者

### 配置檔案設定

在 `config.py` 中新增模式選擇參數：

```python
# config.py

# === 休息提醒模式設定 ===
REST_REMINDER_MODE = "TIMER"    # 休息提醒模式選擇
                                # "TIMER"   - 倒數計時器模式
                                # "IMAGE"   - 圖片提醒模式

# === 圖片提醒設定 ===
REST_IMAGE_PATH = "images/image.png"    # 休息提醒圖片路徑
IMAGE_DISPLAY_MODE = "WINDOW"           # 圖片顯示模式
                                        # "WINDOW"     - 視窗模式
                                        # "FULLSCREEN" - 全螢幕模式
```

#### 錯誤處理機制
- **圖片檔案不存在**：自動切換至計時器模式並提示使用者
- **無效模式設定**：預設使用計時器模式
- **圖片格式不支援**：支援常見格式（PNG、JPG、GIF）

## 時間設定參數功能詳解

### 1. **WORK_DURATION** (3600秒 = 1小時)
**功能**：工作時長統計和長時間工作提醒
- **作用**：當連續工作達到1小時時，系統會發出「已工作1小時」的提醒
- **目的**：追蹤工作時長，提醒使用者注意工作時間
- **觸發條件**：檢測到人員在座位上連續1小時

### 2. **REST_INTERVAL** (1800秒 = 30分鐘)
**功能**：定期休息提醒的週期
- **作用**：每工作30分鐘就提醒使用者「該休息了」
- **目的**：預防長時間專注導致的疲勞，符合人體工學建議[1]
- **觸發條件**：從開始工作或上次休息結束後，每30分鐘觸發一次

### 3. **REST_DURATION** (300秒 = 5分鐘)
**功能**：建議的休息時長
- **作用**：提醒使用者「建議休息5分鐘」
- **目的**：給出具體的休息時間建議，確保休息品質
- **應用**：休息倒數計時器、休息完成判定

### 4. **AWAY_THRESHOLD** (300秒 = 5分鐘)
**功能**：離開座位的判定閾值
- **作用**：當檢測不到人員超過5分鐘時，重置工作計時器
- **目的**：避免人員離開時仍在計時，確保工作時間統計準確
- **觸發條件**：連續5分鐘檢測不到人員

### 5. **DETECTION_INTERVAL** (1秒)
**功能**：攝像頭檢測頻率
- **作用**：每1秒檢查一次是否有人在座位上
- **目的**：即時監測人員狀態，確保反應靈敏度
- **影響**：檢測精度和系統資源消耗的平衡點
